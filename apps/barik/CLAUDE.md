## Языки, кэш, дизайн
Шесть языков: ru/en/fr/es/de/pt, португальский бразильский. Правка интерфейса — все шесть.
Язык: сохранённый выбор → ?lang= → страна по поясу → английский. Армению в TZ_LANG.ru не возвращать. Язык браузера — предложение, не автопереключение.
Обложка из HTML до скриптов; класс nopre для вернувшихся/нужного языка не убирать. dump_words.js снимает обложки, build_site.py вкладывает их в страницы.
Словарь в сборке разделён: data.js — hy/emoji, tr-<язык>.js — переводы, lang0.js грузит английский и язык гостя; смена через trLoad. Новое поле/язык — TR_COL, TRC, lang0.js. Использовать w.r/e/f/s/de/pt.
Меняемые файлы — no-cache; главная в SW из сети, установка SW cache: reload, audio/manifest.json из сети. JS/CSS с отпечатком ?v=, SHELL с теми же адресами. Записи/картинки по содержимому, шрифты 30 дней.
Дизайн «Тёплый Ереван»: Manrope, гранат с листком, уникальные id SVG-градиентов. Арарат и пара снежных конусов запрещены; гора — Арагац. После обложки make_og.js, после знака make_icons.js.
