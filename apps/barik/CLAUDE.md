- **Как идёт:** заглавная, потом строчная (вкладки; у «և» одна часть), каждая показывается крупно —
  viewBox по рамке части (не меньше линий 64…100). Серый образец толщиной в палец, текущий штрих
  подсвечен, оранжевая точка — откуда вести, по штриху бежит точка — куда. Принятый штрих остаётся
  чернилами ученика, неверный краснеет и гаснет; два промаха подряд — перо само пишет этот штрих.
  «Показать» — перо пишет всю часть (тот же `writeCursive`), «Без образца» — по памяти, допуски ×1.35.
- **Сверка** (`penCheck`): штрих и эталон (`getPointAtLength`, 48 точек) делятся на равные по длине
  куски и выравниваются DTW. Отказ с причиной: «с другого конца» (`rev`), «не от точки» (`start`, дальше

  дальний уход > 44 px, эталон не покрыт на 36 px). **Допуски в пикселях экрана** (`PEN`), не в единицах
  буквы: палец везде одинаковый, а буква на экране разного размера. Оценка штриха `1−(средн−4)/14`;
  точность буквы — среднее, ★★★ от 80%, ★★ от 55% (4+ промаха — на звезду меньше). Лучшее — `S.pen`

- **Касания:** Pointer Events (палец, мышь, стилус — одно и то же), `getCoalescedEvents` для плавной

## Цель
Подписанный AAB для Google Play: приложение работает офлайн, все слова озвучены записями нейроголоса,
бесплатен уровень A1 и алфавит, остальное — по подписке через Google Play Billing (RevenueCat). Интерфейс на русском и английском.

## Что уже есть в `web/index.html` (одна страница, чистый JS, без фреймворков)
- 3754 слова в 81 теме, уровни A1–C2 (поле `lv` у темы). Данные — массив `TOPICS`: у тем A1 — массив `w`
  `[слово, перевод, картинка]`, у остальных — строка `d`, по строке на слово: `слово|перевод|эмодзи`
  (пустой эмодзи → плитка с первой буквой).
- Транскрипция — `trWord`. Интервальное повторение по Лейтнеру (1/2/4/7/15/30/60/120 дней), состояние `S`
  в `localStorage` под ключом `hy-vocab-v1`.
- Упражнения: значение слова, выбор армянского слова, на слух, сборка из букв. Режимы: урок, повторение,
  тренировка темы, «Проверить, что знаю» (30 слов), «Трудные слова», кнопка «Уже знаю», отметки
  «Ошибка в слове» (`S.flag`) с копированием списка.
- Звук: `speak()` → если для уровня задан файл записей (`AUDIO_SRC[lv]` — путь к JSON вида
  `{"слово": "base64 mp3"}`), играет запись (`playReal` / `playB64`); иначе — системный синтез (`speakTTS`).
  В Android WebView синтеза речи нет, поэтому в приложении нужны записи для всех уровней.
- Блок `cloud` (`initCloud`, `flushCloud`, `mergeRemote`, `cloudDocs`) — синхронизация через `window.claude`,
  работает только на claude.ai.
- Шрифты Golos Text и Noto Serif Armenian подключены с Google Fonts.

## Стек (не менять без причины)
- Capacitor, актуальная стабильная версия, только Android. Код остаётся на чистом JS.
- Подписки: `@revenuecat/purchases-capacitor`, entitlement `premium`, продукты `premium_monthly` и `premium_yearly`.
- Звук: с O-135 — файл на слово `www/audio/<голос>/<ab>/<aid>.mp3` (раздел «Озвучка» выше); старая схема
  `AUDIO_SRC` (base64 JSON по уровням) убрана — на 20 тыс. слов файл уровня весил бы десятки МБ.
- Шрифты — локально в `www/fonts/` (лицензия OFL), подмножество: кириллица и армянский.
