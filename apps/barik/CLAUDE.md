## Цель
Подписанный AAB для Google Play: приложение работает офлайн, все слова озвучены записями нейроголоса,
бесплатен уровень A1 и алфавит, остальное — по подписке через Google Play Billing (RevenueCat). Интерфейс на русском и английском.

## Что уже есть в `web/index.html` (одна страница, чистый JS, без фреймворков)
- 3754 слова в 81 теме, уровни A1–C2 (поле `lv` у темы). Данные — массив `TOPICS`: у тем A1 — массив `w`
  `[слово, перевод, картинка]`, у остальных — строка `d`, по строке на слово: `слово|перевод|эмодзи`
  (пустой эмодзи → плитка с первой буквой).
- Транскрипция — `trWord`. Интервальное повторение по Лейтнеру (1/2/4/7/15/30/60/120 дней), состояние `S`
  в `localStorage` под ключом `hy-vocab-v1`.
- Упражнения: значение слова, выбор армянского слова, на слух, сборка из букв. Режимы: урок, повторение,
  тренировка темы, «Проверить, что знаю» (30 слов), «Трудные слова», кнопка «Уже знаю», отметки
  «Ошибка в слове» (`S.flag`) с копированием списка.
- Звук: `speak()` → если для уровня задан файл записей (`AUDIO_SRC[lv]` — путь к JSON вида
  `{"слово": "base64 mp3"}`), играет запись (`playReal` / `playB64`); иначе — системный синтез (`speakTTS`).
  В Android WebView синтеза речи нет, поэтому в приложении нужны записи для всех уровней.
- Блок `cloud` (`initCloud`, `flushCloud`, `mergeRemote`, `cloudDocs`) — синхронизация через `window.claude`,
  работает только на claude.ai.
- Шрифты Golos Text и Noto Serif Armenian подключены с Google Fonts.

## Стек (не менять без причины)
- Capacitor, актуальная стабильная версия, только Android. Код остаётся на чистом JS.
- Подписки: `@revenuecat/purchases-capacitor`, entitlement `premium`, продукты `premium_monthly` и `premium_yearly`.
- Звук: существующий механизм `AUDIO_SRC` — файлы `audio_A1.json` … `audio_C2.json` в `www/audio/`.
  Плеер переписывать не нужно.
- Шрифты — локально в `www/fonts/` (лицензия OFL), подмножество: кириллица и армянский.

## Этапы
1. **Каркас.** `npm init`, `@capacitor/core`, `@capacitor/cli`, `@capacitor/android`, `npx cap init`
   (appId и название спроси у владельца), `www/index.html` из `web/index.html`, `npx cap add android`,
   debug-сборка, запуск на телефоне по USB или в эмуляторе Android Studio.
2. **Под приложение.** Удали блок `cloud` и его вызовы. Шрифты — локально. Ни одного внешнего запроса
   (проверь поиском `http` по `www/`). Кнопка «Назад» Android (`@capacitor/app`): из урока и вложенных экранов —
   на главную, с главной — выход. Цвет status bar под светлую и тёмную тему, safe-area.
3. **Озвучка.**
   - Если владелец дал `hy_audio.zip` — распакуй его в `www/audio/`.
   - Иначе: ключ Azure положи в `.env` (`AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION`, шаблон — `.env.example`)
     и запусти `python3 tools/gen_audio.py` (голос по умолчанию `hy-AM-AnahitNeural`; при обрыве — запусти
     снова, готовое не перезапрашивается). Скопируй `tools/audio_*.json` в `www/audio/`.
   - Заполни `AUDIO_SRC = {A1:'audio/audio_A1.json', …, C2:'audio/audio_C2.json'}`.
   - Убери выбор системного голоса и пометки «≈ русский голос по транскрипции».
   - Проверь на телефоне: автоозвучка, «Слушать», «Медленно», упражнение «на слух». Сообщи размер AAB.
4. **Хранилище.** `localStorage` в WebView сохраняется — оставь его (или `@capacitor/preferences` с миграцией).
   Формат `S` не менять.
5. **Подписка.** Бесплатно — весь уровень A1 (413 слов). Темы A2–C2 — с замком и экраном подписки:
   месяц и год, пробный период (если настроен в Play Console), «Восстановить покупки», ссылки на политику
   конфиденциальности и условия. Доступ — по `customerInfo.entitlements.active.premium`, статус кэшировать для
   работы офлайн. Ключ RevenueCat (public Android SDK key) спроси у владельца, держи в `src/config.js`.
6. **Вид.** Иконка — буква «Ա» на абрикосовом фоне `#EC8B2E`, adaptive icon, splash. Ни на одном экране нет
   горизонтальной прокрутки.
7. **Релиз.** keystore через `keytool` (пароль спроси, храни в `keystore.properties`, он в `.gitignore`),
   versionCode / versionName, targetSdk — тот, что сейчас требует Google Play, `./gradlew bundleRelease` →
   подписанный AAB. Напиши владельцу, где лежит файл и какой keystore сохранить в надёжном месте.
8. **Материалы для стора** — в `store/`: описание (ru, en), политика конфиденциальности (`privacy.md`:

- Интерфейс на русском и английском. Армянский — восточный, реформированная орфография. Слова и переводы не менять без запроса.
- Логику повторения и упражнений переносить как есть.
- Секреты — только в `.env`, `local.properties`, `keystore.properties`; все они в `.gitignore`.
- Отметки «Ошибка в слове» и экран «Отмеченные слова» сохранить — они нужны для вычитки словаря.
