# Ответы для формы Data safety (Play Console → Политика → Безопасность данных)

| Вопрос | Ответ |
|---|---|
| Собирает ли приложение или передаёт какие-либо из обязательных типов данных? | **Да** — только из-за покупок (RevenueCat) |
| Все ли данные шифруются при передаче? | **Да** (HTTPS) |
| Можно ли запросить удаление данных? | **Да** — прогресс удаляется кнопкой «Сбросить прогресс» или вместе с приложением; данные RevenueCat — по запросу разработчику |

Типы данных (отметить только это):

| Категория | Тип | Собирается | Передаётся | Обязательно | Зачем |
|---|---|---|---|---|---|
| Финансовая информация | История покупок | Да | Нет | Да | Функциональность приложения (проверка подписки) |
| Идентификаторы устройства или другие идентификаторы | Идентификаторы устройства или другие | Да | Нет | Да | Функциональность приложения (анонимный ID RevenueCat) |

Всё остальное (местоположение, контакты, личная информация, фото, аудио, файлы, календарь, сообщения, здоровье, активность в приложении, журналы сбоев, веб-история) — **не собирается**.

Примечание: обработчики, которые действуют от имени разработчика (RevenueCat), Google не считает «передачей третьим лицам».

Другие формы Play Console:
- **Реклама:** нет рекламы.
- **Доступ к приложению:** все функции доступны без входа; для проверки Premium — тестовые аккаунты лицензирования (Play Console → Настройки → Тестирование лицензий).
- **Возрастной рейтинг (IARC):** образование, без насилия и пользовательского контента → 3+.
- **Целевая аудитория:** 13+ (не «для детей», чтобы не попадать под программу Families).
- **Новостное приложение:** нет. **Госприложение:** нет. **Финансовые функции:** нет.
