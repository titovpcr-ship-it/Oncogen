## Находки

1. **Первый урок гостя — 40 шагов.** После «Продолжить урок» на обложке счётчик показывает «1/40» (10 новых слов). Для
   человека из ролика это стена; до `lesson_done` он не доживает.
2. **Гость не из англоязычной страны ждёт обложку 7,5 с** (замер O-220, медленная сеть): ждёт `data.js` (644 КБ) и
   `tr-ru.js` (491 КБ). Английская обложка из HTML — 0,75 с.
3. **Утренняя сводка в Telegram не показывает воронку** — шаги «гости → телефон → вошли → 1-й ответ» и Путь по ступеням
   есть только в `stats.py`, который владелец сам не запускает.
4. **В задании «Что это значит?» (зёрна) картинка выдаёт ответ**: у «դու» — указывающая рука, у «նուռ» — гранат. Это
   проверка картинки, а не слова.
5. **Выкладка при упавшем тесте** (O-220): `check_all.sh | tail -1 && …` не останавливает цепочку. Нужна одна команда
   «тесты → сборка → выкладка → проверка», которая падает сама.
6. **Генерация примеров падает от одного обрыва связи** — B2 сегодня остановился на 181 фразе из ~5 200 и стоял.
7. **Поиск: 0 страниц в индексе Google.** Страниц слов без содержимого (noindex) — 6 134 из 20 121 на язык; остальные
   83 тыс. Google сканирует, но не берёт — вероятно, считает однотипными.
8. Мелочи: подпись таблицы формы — шрифтом с засечками (остальное — Manrope/Inter); `stats.py` — предупреждение
   `utcfromtimestamp`; не проверено, виден ли телефон на первом экране обложки на телефоне без прокрутки.

## Задание для Opus — по порядку

**1. Одна команда выкладки.** `tools/ship.sh`: `check_all.sh` → при «упало: 0» сборка, `deploy_site.py`, `check_live.py`
(до трёх попыток с паузой 30 с — заглушка хостинга); любой провал — код возврата ≠ 0 и выкладки нет. В памяти Barik —
«выкладывать только через ship.sh». *Готово, когда:* тест-заглушка с упавшим тестом не доходит до выкладки.

**2. Первый урок — короткий.** Гость (нет `S.w` кроме слов с обложки, урок ещё не закончен ни разу) получает 4 слова
(≈14–16 шагов); на экране результата — «Ещё 4 слова» и «На главную». Со второго урока — размер из настроек. Событие
`lesson_done` — как сейчас. *Готово, когда:* тест видит у гостя счётчик не больше 16 шагов и обычный размер после.

**3. Телефон — на первом экране.** На 390×700 без прокрутки видны: заголовок, кнопка и телефон с ответами (хотя бы два
варианта целиком). Если нет — поднять телефон выше или сократить отступы. Снимки 360, 390, 430 px. Тест на положение.

**4. Обложка за ≤ 1,5 с на всех шести языках.** Фрагменты обложек для ru/fr/es/de/pt уже строятся (`covers` в
build_site/build_seo). Скрипт до `<main>` (тот, что ставит `nopre`) для гостя из страны со своим языком подгружает
фрагмент `cover-<язык>.html` и вставляет в `#view`, пока идут большие скрипты; приложение потом рисует поверх. Замер
как в O-202/O-220 для Москвы: до и после. Вернувшимся — как сейчас.

**5. Воронка в утренней сводке.** В сообщение `watch_daily` за вчера: «Новички: гости N → телефон N → вошли N → 1-й ответ
N → урок N», «Путь: p1 открыли→прошли→не прошли …» (если не пусто), «из роликов: N», «отчёты CSP: N» (если не ноль).
Тест в `test_watch.js`.

**6. Зерно без подсказки.** В задании `seed` картинку показывать после ответа (до ответа — слово, транскрипция и кнопка
«Слушать»). Тест.

**7. Генерация не падает.** `gen_examples.py`: сетевые ошибки — пауза и повтор (до 10 раз), запись сделанного после каждой
пачки (проверить, что так и есть). Довести B2: сверка `check_examples.py` (только новые), правки, `build_examples.py`,
озвучка обоими голосами (`--max-chars 6000000`), выкладка. Срок — до 01.12 (кредит Azure до 03.12).

**8. Поиск: почему 0 в индексе.** (а) Тест: ни одной страницы с `noindex` в sitemap и в hreflang-парах. (б) На 30
случайных страницах слов сравнить текст попарно: доля общего текста (шаблон) — в отчёт; если шаблон > 70 % — уменьшить
повторяющиеся блоки (подвал, одинаковые абзацы «как учить»), поднять уникальное выше: пример, формы, семья корня.
(в) Со страницы слова — ссылки на 6–8 слов той же темы и семьи (если ещё нет). IndexNow не слать.

**9. Мелочи.** Подпись `.g-tab caption` — шрифтом интерфейса; `stats.py` без предупреждения `utcfromtimestamp`;
≈19.11 — боевой `Content-Security-Policy`, если в сводке нет отчётов CSP.
