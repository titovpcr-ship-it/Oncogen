## Находки

1. **Защита хостинга от ботов иногда подменяет файл заглушкой.** 1 запрос из 12 к `pics/1f319.webp` вернул HTML
   «One moment, please…» (12 КБ) вместо картинки; при загрузке главной одна картинка получила 415. Замер шёл из
   дата-центра — для обычных телефонов доля неизвестна. Риск: то же получают поисковые роботы.
2. **Сигнала о поломке нет.** Упадёт сайт, оплата или почта — владелец узнает от посетителя.
3. **Воронка неполная.** `hit('start')` стоит только на `pickLang`; вход через «Открыть», алфавит, пропись, страницу
   поиска не считается. Нет событий «первый ответ», «увидел замок → оформил».
4. **`stats` считает Premium без учёта режима** (`index.php`: `sub_status IN (...)` без `sub_here`): показывает 1 —
   это старая тестовая подписка владельца.
5. **Канонический адрес оглавлений — `/en/index.html`**, а люди и ссылки приходят на `/en/`: два адреса одной страницы
   (то же у `/p/`, `/a/`, `/g/`, `/n/`, `/t/` — проверить все).
6. **Главная для поиска только английская.** Обложка на ru/fr/es/de/pt существует лишь внутри приложения
   (`/?lang=ru`), у главной нет hreflang. По запросу «учить армянский онлайн» показывать нечего, кроме оглавления словаря.
7. **Анкета перед оплатой: 5 обязательных полей** (O-196). Dodo нужны имя и страна; дата рождения и пол — лишний шаг
   и лишние личные данные. Решение — владельца (см. «Вопросы владельцу»).
8. **Главная тяжелее остального:** LCP 2,9 с при 0,4 с у страниц поиска.
9. **Копии базы ни разу не восстанавливались** — неизвестно, поднимется ли сайт из архива.
10. **DMARC `p=none`, CSP нет.** Не срочно, но с оплатой и кабинетом — пора.
11. Мелочи: всплывающая подсказка «Перед оплатой заполните…» ложится поверх поля «Дата рождения» (360 px).

## Задание для Opus — по порядку

### 1. Измерить, прежде чем менять (1 день)
- Воронка гостя: события `land_cta` (с меткой кнопки: start / open / abc / pen / letter / name), `seo_open` (переход со
  страницы поиска в приложение, со страницы — её тип w/t/p/a/g/n), `first_answer`, `lesson_done`, `v_paywall`,
  `checkout`, `profile`, `paid` (после `cardReturn` с Premium). `start` считать на любом входе с обложки.
- `tools/stats.py`: таблица воронки по дням «гости → нажали → первый ответ → урок → замок → оформление → оплата» и
  разрез по языку и по источнику (`r`).
- Исправить Premium в `stats` — только подписки текущего режима и подарки.
- `res_fail`: счётчик незагрузившихся картинок, скриптов и записей (обработчик `error`), в сводке — доля от открытий.
**Готово, когда:** `test_app.js` проверяет каждое событие; `stats.py` печатает воронку; Premium у владельца до оплаты — 0.

### 2. Заглушка хостинга вместо файлов (находка 1)
- Через cPanel (443) взять журнал доступа за 3 дня, посчитать ответы с заглушкой и 415: всего, по типу файла, по
  User-Agent (Googlebot, YandexBot, Bingbot, iPhone, Android).
- Подготовить владельцу текст обращения в поддержку Name.am: не проверять статичные файлы (`/pics/`, `/audio/`, `/js/`,
  `/css/`, `/fonts/`) и поисковых роботов. **Защиту не обходить** — только настройка хостинга через поддержку.
- До ответа поддержки: картинка, не пришедшая с первого раза, запрашивается ещё раз через 1,5 с (один повтор).
**Готово, когда:** цифры в ISSUES, текст обращения у владельца, повтор покрыт тестом.

### 3. Сигнал о поломке
- Ежедневная проверка из облака: `check_live.py` + вход по коду на тестовый ящик + `dodo_setup.py --check` → при сбое
  сообщение владельцу в Telegram (бот уже есть). Расписание — **только по слову владельца**.
- В `cron.php` (раз в час на хостинге): свежие строки журнала ошибок PHP, неудачные вебхуки Dodo, место на диске > 80 %,
  срок сертификата < 14 дней → Telegram владельцу, не чаще раза в сутки на причину.
- Ошибки JS у посетителей: `hit('js_err')` + последние 50 сообщений в таблице, вывод в `stats.py`.
**Готово, когда:** тест `test_tg.js` покрывает оповещение; учебная поломка (неверный секрет в тестовой среде) даёт сообщение.

### 4. Обложка на шести языках для поиска (находки 5 и 6)
- Статичные страницы `/<язык>/learn.html`: обложка `onboardHTML` на своём языке, отрисованная при сборке (как
  `make_og.js`), со своим title и description из `land`, hreflang ×6 + x-default, кнопки ведут в `/?lang=<язык>`.
  В sitemap и в подвал страниц поиска. Главная `/` получает hreflang на них.
- Канонические адреса оглавлений — в виде папки (`/en/`, `/ru/p/`…): canonical, sitemap, внутренние ссылки; `index.html`
  → 301 на папку. После выкладки — `tools/indexnow.py`.
**Готово, когда:** `test_seo.js` проверяет 6 обложек, hreflang главной, отсутствие `index.html` в canonical и sitemap.

### 5. Первый урок прямо на обложке (после данных задачи 1)
