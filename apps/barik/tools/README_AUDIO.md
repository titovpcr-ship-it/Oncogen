# Озвучка: ключ Azure и запуск (O-135)

Голоса Microsoft для восточноармянского: женский `hy-AM-AnahitNeural` (по умолчанию, им озвучен словарь)
и мужской `hy-AM-HaykNeural`. Это официальный сервис с коммерческой лицензией — подходит для платного
продукта; в «О приложении» и в настройках звука сказано, что голос синтезированный.

## Ключ (один раз, около 10 минут; владелец завёл 03.11.2026)
1. portal.azure.com → бесплатная пробная подписка (телефон и карта не российского банка; страна в анкете
   — страна карты, потом не меняется).
2. Поиск **Speech** → «Службы речи» → «Создать»: группа ресурсов `Barik`, регион **North Europe**
   (West Europe новых клиентов не принимает: «RequestDisallowedByAzure … not accepting new customers»),
   ценовая категория **Free F0**, сеть — «Все сети, включая Интернет».
3. В службе: «Ключи и конечная точка» → **КЛЮЧ 1** и **регион** (`northeurope`).
4. `.env` рядом с `package.json` (шаблон `.env.example`, права 600, в git не попадает):
   `AZURE_SPEECH_KEY=…` и `AZURE_SPEECH_REGION=northeurope`.

## Запуск
```
python3.13 tools/gen_audio.py                 # всё, чего нет: слова + названия букв
python3.13 tools/gen_audio.py --check         # без запросов: чего не хватает, обновить manifest.json
python3.13 tools/gen_audio.py --only L        # только буквы
python3.13 tools/gen_audio.py --limit 200     # проба
python3.13 tools/gen_audio.py --redo 'և'      # переозвучить записи, где текст подходит под выражение
python3.13 tools/gen_audio.py --voice hy-AM-HaykNeural   # мужской голос — в свою папку audio/hayk/
```
Новое слово в словаре → `build_data.py` → `gen_audio.py` (озвучит только новое) → `node tests/test_app.js`
(тест падает, если у слова нет записи).

## Как устроено
- **Файл на слово:** `www/audio/<голос>/<ab>/<aid>.mp3`, `aid` — два FNV-1a по UTF-8 текста (16 знаков;
  тот же считает `aid()` в `www/js/app.js`), `ab` — первые два знака. MP3 VBR (`-q:a 7`), 24 кГц, моно,
  ~4,5 КБ на слово. `www/audio/manifest.json` — голос, папка, сколько записей. Готовое не перезапрашивается.
- **Бесплатный тариф F0:** 20 запросов в минуту и 0,5 млн знаков в месяц, причём в знаки идёт и разметка
  SSML (всё, кроме `<speak>` и `<voice>`). Поэтому слова идут **пачкой по 50 в одном запросе через перевод
  строки**: Azure читает каждую строку отдельной фразой с паузой ~1 с, запись режется по паузам (речь
  громче −45 дБ, паузы короче 0,45 с — внутри фразы, хвост до −60 дБ, запас 60/120 мс). Число кусков и их
  длина сверяются со словами (речь ≈ 0,25 с + 0,06 с на знак, допуск 0,4–2,4); не сошлось — пачка делится
  пополам и озвучивается заново, до одного слова. Фразы с запятой и длиннее 45 знаков — по одной.
  `<prosody rate='-5%'>` — один на пачку (на каждое слово он съел бы ~620 тыс. знаков).
- **Лигатура «և»:** голос Azure её глотает (одна «և» — пустой WAV, «սև» — 0,17 с вместо 0,55, «բարև» —
  без «ев» на конце). В запрос идёт «եւ» (`spoken()` — то же произношение), имя файла — по слову.
  Переозвучить по выражению: `python3.13 tools/gen_audio.py --redo 'և'`.
- Знаки по месяцам — `tools/audio_usage.json`; дальше `--max-chars` (450 тыс.) за месяц скрипт не идёт.
  Длительности и пачки последнего прогона — `dist/audio_meta.json` (не в git).
- **Воспроизведение** (`app.js`): запись берётся `fetch` целиком (на сайте — через service worker, он
  хранит её в `barik-audio-v1`, без интернета звучит прослушанное) и играется из `blob:`; плееру ссылку на
  файл не даём — он просит файл кусками (Range), а куски из кэша service worker Safari не играет. Слова урока
  и темы (до 60) берутся заранее. Нет записи — системный армянский голос, если он есть.
