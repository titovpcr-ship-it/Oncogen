# Армянские слова → Android-приложение: что сделать

Внутри архива:
- `web/index.html` — готовое приложение: 3754 слова, уровни A1–C2.
- `CLAUDE.md` — техзадание. Claude Code читает его сам и собирает приложение по этапам.
- `tools/` — скрипт озвучки армянским нейроголосом и список слов (`README_AUDIO.md` — как получить ключ).
- `.env.example` — шаблон для ключа Azure.

## Шаг 1. Компьютер — один раз, около часа
1. **Android Studio** — developer.android.com/studio. При первом запуске пройдите мастер установки: SDK и Java поставятся сами.
2. **Node.js LTS** — nodejs.org.
3. **Python 3** — python.org (для скрипта озвучки; на macOS и Linux обычно уже есть).
4. **Claude Code** (нужна подписка Claude Pro или Max):
   - macOS / Linux: `curl -fsSL https://claude.ai/install.sh | bash`
   - Windows (PowerShell): `irm https://claude.ai/install.ps1 | iex`, плюс Git for Windows с git-scm.com — с ним Claude Code работает полноценно.
   - Без терминала: приложение Claude для компьютера с claude.com/download, вкладка Code.

   После установки наберите в терминале `claude` и войдите через браузер.
5. **Android-телефон для проверки:** Настройки → «О телефоне» → 7 раз нажать «Номер сборки» → в разделе «Для разработчиков» включить «Отладка по USB» → подключить кабелем. Без телефона можно проверять в эмуляторе Android Studio.

## Шаг 2. Аккаунты — можно параллельно
1. **Google Play Console** (play.google.com/console) — $25 один раз, личный аккаунт, проверка по паспорту.
   - Профиль платежей и счёт для выплат — армянские: разработчикам со счетами в российских банках Google с 26.12.2024 монетизацию не даёт.
   - Для личного аккаунта перед выпуском обязательно закрытое тестирование: 12 тестировщиков 14 дней подряд. Ищите тестировщиков сразу — это самое долгое.
2. **RevenueCat** (revenuecat.com) — бесплатно, пока выручка до $2 500 в месяц, дальше 1%. Создайте проект и Android-приложение. Как связать его с Play Console, Claude Code подскажет на этапе 5.
3. **Azure Speech** — для озвучки, см. `tools/README_AUDIO.md`. Бесплатного тарифа хватает на весь словарь.
   Если ключ заводить не хотите — озвучку можно сделать отдельно через hy-audio-kit (запуск с iPhone через GitHub) и положить готовый `hy_audio.zip` в эту папку.

## Шаг 3. Сборка в Claude Code
1. Распакуйте архив, например, в «Документы/armenian-app».
2. Озвучка: либо положите в папку готовый `hy_audio.zip`, либо скопируйте `.env.example` в `.env` и впишите ключ и регион Azure.
3. Откройте терминал в папке `armenian-app` и запустите `claude`.
4. Первое сообщение:
   **«Прочитай CLAUDE.md и выполни этап 1. После каждого этапа останавливайся и пиши, что мне проверить на телефоне.»**
5. Проверили на телефоне → пишете «Всё работает, переходи к следующему этапу». appId, ключи и пароль Claude Code спросит сам.

Этапов восемь, на всё — один-два вечера.

## Шаг 4. Публикация в Google Play
1. Play Console → «Создать приложение».
2. «Монетизация» → «Подписки»: создайте `premium_monthly` и `premium_yearly` (ID как в CLAUDE.md), цены, при желании — пробный период.
3. «Тестирование» → «Закрытое тестирование»: загрузите AAB (Claude Code скажет, где файл), добавьте 12+ тестировщиков по адресам Gmail, ждите 14 дней.
4. Карточка приложения — из папки `store/`: описание, скриншоты, форма Data safety. Политику конфиденциальности разместите по публичной ссылке, например на Google Sites.
5. После теста — заявка на выпуск. Комиссия Google с подписок — 15%.

До релиза — 3–5 недель, в основном из-за закрытого теста.

## Важно
- **Файл подписи (keystore) и пароль** храните минимум в двух местах. Без них выпуск обновлений сильно усложнится.
- **Вычитка словаря:** перед продажей покажите словарь носителю. Подозрительные слова отмечайте кнопкой «Ошибка в слове?» на карточке слова — список копируется в «Настройки → Отмеченные слова».
- **Россия:** в RuStore продавать подписку можно только через ИП — с 1 февраля 2026 самозанятых отключили от платежей. Комиссия — 15%. Это этап 9 в CLAUDE.md.
- **Налоги:** для налогового резидента РФ доход от Google — иностранный. Декларация 3-НДФЛ — до 30 апреля следующего года, налог — до 15 июля, об армянском счёте нужно уведомить ФНС в течение месяца. Детали лучше уточнить у бухгалтера.
