# Арсенал возможностей

Составлено 06.09.2026. Всё, что ниже, либо замерено на живых данных, либо
помечено как допущение. Числа без пометки «оценка» — результат измерения.

---

## 1. Что система делает вообще

Ищет винил на eBay у продавцов из США, оценивает его по Discogs и по
московскому рынку, считает полную себестоимость до Москвы и присылает в
Telegram то, что прошло сторожей. Решение о покупке — всегда за человеком.
Ставки не автоматизируются, таможня не считается.

Сейчас работают **два режима**. Они независимы и решают разные задачи.

| | `tools/new_pop.py` | `tools/live_hunt.py` |
|---|---|---|
| Статус | **приоритет с 03.09.2026** | запаркован (не удалён) |
| Что ищет | новую попсу из топ-листа | редкости с абсолютной прибылью |
| Критерий | цена до форвардера ≤ порога | прибыль ≥ $40 |
| Объём | ~860 живых листингов в срезе | 3952 помеченных лота |
| Результат | 256 позиций отправлено | ноль прошедших, лучший $49.74 |
| Запуск | вручную, автозапуск снят | вручную |

## 2. Режим «новая попса» — `tools/new_pop.py` (518 строк)

### Что это
Топ-лист ходовых в РФ новых пластинок (24 позиции из исследования владельца
от 02.09.2026 — Wildberries, Ozon, Яндекс Маркет, витрины профильных
магазинов, Official Charts UK за 1П2026). По каждой позиции — запрос к eBay,
фильтрация, расчёт цены входа, отправка в Telegram.

### Что умеет
- **Фильтр eBay `buyingOptions:{BEST_OFFER}`** — проверен живьём: настоящий
  фильтр, а не косметика. Taylor Swift: 10260 → 5991 лотов.
- **Воронка фильтров замерена** на одном запросе:
  2131 → 2096 (категория 176985 Records) → 1562 (США) → 479 (New) → 196 (Best Offer).
- **Цена входа** = `max(0, price − скидка) + (доставка продавца или допущение)`.
  Скидка и надбавка за доставку взяты **из фактических покупок владельца**,
  а не из головы.
- **Отсев ложных совпадений** — `same_release(artist, album, title)`:
  строгий `title_matches` здесь замерен как непригодный, сделана отдельная
  функция. Отдельно отсекаются наклейки/постеры вместо пластинки
  (`_STICKER_AS_ITEM`), синглы 7″ (`_SEVEN_INCH`), «не тот товар»
  (`_NOT_THE_THING`).
- **Групповая отправка** `--batch N` — не по одному пушу на лот.
- **Память об отправленном**: таблица `newpop_seen` (сейчас 256 позиций).
  Повторно то же самое не приходит — по прямой просьбе владельца.
- **Сухой прогон** `--dry` — считает и печатает, ничего не шлёт.
- **Порог задаётся с командной строки** `--max-landed 33`, конфиг не трогается.

### Требование «sealed» снято 03.09.2026
Замерено: слова «sealed» в заголовке не было у **422 лотов из 847** — это был
крупнейший отсев режима, крупнее цены. Владелец руками просмотрел 44 такие
позиции и нашёл годные. Честная оговорка, записанная в конфиг: отсутствие
слова не означает ничего — 32 из тех 44 имели автоматический заголовок вида
«Thriller by Jackson, Michael (Record, 2016)», где о состоянии не сказано
вообще. Цена решения — обязательная ручная сверка фото и описания.

### Команда
```
python3 tools/new_pop.py --max-landed 33 --batch 8
python3 tools/new_pop.py --max-landed 25 --dry        # посмотреть, не отправляя
```

## 3. Режим «охота за редкостями» — `tools/live_hunt.py` (1169 строк)

Запаркован, но полностью рабочий. Здесь собрана вся тяжёлая логика оценки.

### Опознание пластинки
- **Поиск по каталожному номеру** (`resolve_by_catno`) — структурный запрос
  Discogs `catno=`. Решает альбомы, чьё название не названо в заголовке лота.
- **`card_matches`** вместо строгого `verify_match`. Замер на неопознанных:
  старая функция **0 из 60**, новая **21 из 60**. Опознание по всему корпусу
  поднялось с ~44% до ~66%.
- Ветвление по природе карточки: одноимённая карточка (альбом назван как
  артист) проверяется строго, обычная — все слова артиста плюс 2/3 слов
  альбома, причём **слова артиста исключаются из доказательства** — иначе
  self-titled ловушки проходят.
- **`_catno_same`** — хвост `-[A-Z]\d?` снимается, числовой хвост никогда.
  Выросло из двух потерь: `BN-LA738-H` резался до `LA738` (потеряно $46.37),
  `CPM1-0818` не сходился с `CPM1-0818-A` (потеряно $404.05).

### Сторожа оценки — каждый из живого случая
| Сторож | Живой случай, который его породил |
|---|---|
| `pressing_mismatch` (год / том / каталожный номер) | Jackie McLean за $550 — оценивался по чужому прессу |
| `cargo_usd` по весу, не флэт | бокс Creedence: считалось $16.50, реально ~$86 |
| `condition_report` — чтение описания лота | Bennie Green G+ с прожогом от утюга, состояние не читалось вообще |
| `conservative_reference` | Savoy Brown promo с оби: эталон строился по **одной** копии |
| `west_min_num_for_sale: 3` | одна копия на продаже — это мнение одного продавца, а не рынок |
| `grade_from_text` | «180 g» распознавалось как grade G |

### Порядок вычислений
Экономика **до** спроса — замерено, что обратный порядок убивал 77 лотов
из 150, ни разу не посчитав прибыль. Вся цепь отказа сведена в одну функцию
`verdict()`: пресс → состояние → спрос.

### Очередь
`order_key()` — срочное раньше перспективного; **внутри** срочных решает срок,
а не очки. Вынесена на уровень модуля специально, чтобы тест проверял
рабочий код, а не свою копию логики.

### Оценка перспективности
`promise()`: метка на пластинке весит 4, дешевизна +1, отсутствие ставок +1.
Вес метки поднят с 2 до 4 после замера — при весе 2 метка (7699 лотов)
уравнивалась с «дёшево и без ставок» (337 лотов).

## 5. Источники данных и их измеренные причуды

### eBay Browse API
- Квота **5000 запросов в сутки**, сброс в 07:00 UTC. Остаток проверяется
  живьём: `developer/analytics/v1_beta/rate_limit`.
- `offset` **обязан** быть кратен `limit` — иначе отказ.
- **74% листингов несут `shippingCostType: CALCULATED` без суммы.** Отсюда
  допущение о доставке: подставлять ноль нельзя, это уже стоило 52%
  заниженных landed на аукционах.
- `itemCreationDate` даёт возраст листинга.
- Карточка товара `buy/browse/v1/item/v1|{id}|0` отдаёт
  `conditionDescription` и `shortDescription` — **только там** живёт грейд
  от продавца.

### Discogs API
- **60 запросов в минуту на все методы вместе.** Это главное узкое место.
- `database/search` понимает структурный `catno=`.
- `marketplace/stats` → `num_for_sale` + `lowest_price` (на этом аккаунте
  приходит в EUR, пересчёт по 1.09).
- `releases/{id}` → `community.want/have`, `labels[].catno`, `country`, `year`,
  `master_id`.
- `masters/{id}/versions` → сравнение внутри семейства прессов.

## 6. Замеренные константы экономики

| Величина | Значение | Откуда |
|---|---|---|
| Карго США → Москва | **$22 / кг** | тариф форвардера |
| Вес посылки | **0.30 кг упаковка + 0.45 кг на диск** | одинарник = 0.75 кг, медиана форвардера |
| Надбавка за доставку | **$5.14** (медиана: 6.13 / 5.13 / 5.14) | три фактические покупки |
| Скидка в торге | **$5.00** | три фактические покупки, **знаменателя нет** |
| Курс | **86.75 ₽/$** | |
| Допущение доставки по США | $5.00 | совпало с замером |

**Важное следствие, которое пришлось пересчитать.** Я сначала сделал вывод,
что доставка бесплатная — по трём покупкам владельца. Владелец поправил: он
**сторговал по $5 у каждого продавца**. После пересчёта скидка и надбавка
взаимно гасятся, то есть цена входа ≈ цене листинга. Старое правило
«price + 5 ≤ 25» выбрасывало всю полосу $20–25 целиком.

## 7. Честные отрицательные результаты

Это не оговорки, это измерения. Они стоят столько же, сколько находки.

- **Охота за редкостями даёт ноль при пороге $40.** Вся помеченная выборка —
  3952 лота — максимум $49.74, и тот единственный. Порог опускался с $50 до
  $40 именно поэтому.
- **Даже при бесплатной логистике** ноль лотов из выборки в 141 позицию
  перешагнул $50.
- **Срез «новой попсы» почти неподвижен**: ~860 живых листингов, из них
  **99% старше суток**. Новых появляется **5–7 в день**. Отсюда решение
  владельца о двух прогонах в сутки — чаще нечего смотреть.
- Ранжирование топ-листа **порядковое, а не позиционное** (оговорка из самого
  исследования владельца): позиции 1–5 и 15–20 различаются уверенно, соседние
  внутри блока — нет. Список правится руками, это не измерение.

## 8. Устав — два правила, которым подчинено всё

1. **Величина, замеренная на одной популяции, никогда не переносится на
   другую.** Прямое измерение бьёт коэффициент.
2. **Каждый ноль обязан ответить**: «посмотрел и отказал» или «не смотрел».

Второе правило вскрыло шесть багов во время внутреннего аудита: отказ API
записывался как ответ (дважды), находка журналировалась до отправки, сухой
прогон хоронил находки, сортировка срочных ломалась (нашёл **тест**), и
`database is locked` — мои собственные аудиторские запросы убивали идущую
охоту. Последнее вылечено WAL + `busy_timeout=60000`.

## 9. Чего система не делает — сознательно

- **Не автоматизирует ставки.** Торг и покупка — человек.
- **Не считает таможню.**
- Не подбирает User-Agent и заголовки ради обхода challenge.
- Не использует сторонние прокси и антибот-сервисы.
- Не ходит по URL, запрещённым robots-политикой, даже когда технически может
  (`test_robots_policy.py` это стережёт).
- Не скрейпит историю продаж Discogs через залогиненную сессию.
- Учётные данные в коде не запрашивает — `MV_LOGIN` / `MV_PASSWORD` из `.env`
  (режим 600, в git не попадает).
- В пуш кладёт только ссылку и цифры: тема ntfy фактически публична.
- `/product/<id>.json` МаркетВинила не трогается без явного разрешения.
- К МаркетВинила не чаще одного запроса в секунду.

**Открытый долг:** токен Discogs зашит в `ebay_vinyl_3x_finder.py:157`.
Владельцу доложено, в `.env` пока не перенесён.

## 11. Тесты

~3550 строк тестов на ~13 650 строк рабочего кода. Ключевые:

- `test_live_hunt.py` — ~58 проверок
- `test_new_pop.py` — ~24 проверки
- `test_robots_policy.py` — стережёт устав
- `test_catno_normalization.py`, `test_resolution_baseline.py` — опознание
- `test_ru_economics.py`, `test_ru_price_model.py` — российская экономика

**Каждая проверка выросла из живого случая, ни одна не придумана.** Один раз
тест дублировал логику сортировки и прошёл бы на сломанном коде — после
этого `order_key` и `verdict` вынесены на уровень модуля.

## 12. Ограничения среды, которые пришлось обойти

- **Фоновые процессы `nohup` не переживают ход, который их запустил** —
  замерено: каждый прогон умирал через 30–60 минут. Работа идёт кусками
  внутри хода, с `timeout`.
- SQLite требует WAL и `timeout=60`, иначе читатель убивает писателя.

## 13. Что запущено прямо сейчас

**Ничего.** Автозапуск снят по просьбе владельца, расписаний не осталось.
Запуск — только руками:

```
python3 tools/new_pop.py --max-landed 33 --batch 8
```
