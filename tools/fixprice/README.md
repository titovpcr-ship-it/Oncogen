# Режим «фикс прайс»

Запечатанные пластинки дешевле $15 на eBay против самой низкой цены
на Discogs. Код — `tools/fixprice/sealed.py`, список исполнителей —
`tools/fixprice/artists.py`.

## Задача владельца, дословно

- 22.10.2026: «пластинки до 15$ новые упакованные, плевать какой жанр,
  можно очень популярные … не аукцион — только режим купить сейчас или
  предложить свою цену. Назовем режим фикс прайс».
- 22.10.2026: «Бери дискогс как метрику, все должно быть в состоянии
  sealed, оно не обязательно в разделе новое, человек может её и как
  б/у указать (кто знает сколько она лежала в комоде упакованная?), то
  есть нашел 15$ продает а на дискогс хотя бы пол 30$».
- 22.10.2026: «30$ это 2x а вдруг ты найдешь 10x кто знает?» — порог
  2x, сортировка по кратности.
- 22.10.2026: «Добавь поиск по каталожному номеру для старых без
  штрихкода».
- 23.10.2026: «Добавь аукционы и прогони повторно».
- 23.10.2026: торг — запрос $15–20, предложение $15.

## Правила отбора

| правило | значение |
|---|---|
| состояние | запечатан: раздел New, или б/у со словом sealed / factory sealed / still in shrink в заголовке |
| снимается | resealed, opened, unsealed, shrink torn/split, no shrink, played |
| способы покупки | купить сейчас и предложить цену; аукционы — флагом `--auctions` |
| страна лота | только США (правило владельца от 22.10.2026) |
| потолок | цена лота до $15 **без доставки**; у аукциона — к текущей ставке |
| торг | `--offer-only --min-buy 15 --max-buy 20 --offer 15`: прибыль считается от предложения $15 |
| опора | самая низкая цена Discogs в долларах по изданиям с этим штрихкодом (или номером) |
| глубина | не меньше 5 копий в продаже на Discogs |
| порог | от 2x к цене лота и прибыль от $3 на руки |
| прибыль | пол × 0.88 (комиссии Discogs и оплаты) − цена − доставка; доставка не объявлена — берётся $5 |
| аукцион | печатается ПРЕДЕЛ СТАВКИ = пол / 2 и прибыль при выигрыше на нём |
| продавец | отзывов не меньше 10; не больше трёх находок с одного продавца |

## Проверки — каждая выросла из ложной находки

1. **Издание — по штрихкоду.** У популярного альбома десятки изданий:
   Abbey Road в плёнке за $15 — свежий тираж с полом ~$18, а не 1969-й.
   Штрихкод из карточки (gtin, UPC, EAN), издание — поиском Discogs по
   коду. Неофициальные тиражи не считаются.
2. **Старые без штрихкода — по каталожному номеру** из карточки
   («Catalog Number») или заголовка, вместе с исполнителем. Номер
   издание не определяет (переиздание наследует номер), поэтому опора —
   самое дешёвое издание с этим номером; пол раннего года печатается
   рядом: «СВЕРИТЬ ЭТИКЕТКУ ПО ФОТО». В поиске по словам (без
   исполнителя) номер не ищется: совпадает у разных лейблов.
3. **Винил должен быть доказан.** Bob Dylan «Time Out Of Mind» за $14.95
   стоял в разделе винила, с «Format: Record» и штрихкодом винилового
   издания, а был CD (сверил владелец по фото). Нужно LP / vinyl / 12" /
   180g / gatefold в заголовке, или размер или скорость в карточке.
4. **Не пластинки отсекаются по заголовку:** постеры, наклейки, кружки,
   бумажные «Vinyl Record Paper Label», трибьюты, игрушки-миниатюры
   Mini Brands (у них штрихкод настоящего альбома), бумажки с кодом
   скачивания, 12" синглы.
5. **Цвет должен совпасть.** Цветные варианты делят штрихкод: Taylor
   Swift «Portofino Orange» лёг на пурпурный вариант с чужой ценой.
   Если заголовок называет цвет, он должен быть в описании издания на
   Discogs. Имя исполнителя и название альбома перед сверкой вырезаются
   («Red Hot Chili Peppers» — не красный винил), оттенки приводятся к
   цвету (cobalt → blue), фактура (glitter, marble, clear) — не цвет.

## Как запускать

```bash
# основной: купить сейчас + торг до $15, по 215 исполнителям
python3.13 -u tools/fixprice/sealed.py --max-items 1800

# с аукционами
python3.13 -u tools/fixprice/sealed.py --auctions --max-items 2600

# торг $15–20, предложение $15, поиск по словам
python3.13 -u tools/fixprice/sealed.py --offer-only --min-buy 15 \
  --max-buy 20 --offer 15 --pages 5 --max-items 650 --queries \
  "limited edition sealed vinyl" "numbered sealed vinyl" \
  "record store day sealed vinyl" "rsd sealed vinyl" \
  "colored vinyl sealed" "exclusive vinyl sealed" \
  "out of print sealed vinyl" "sealed vinyl lp"
```

`--tg` отправляет топ в Telegram с пометкой «НЕ СВЕРЕНО ГЛАЗАМИ». По
стоячему правилу находки сначала проверяются глазами (заголовок,
карточка, фото у верхних), и только подтверждённые уходят в Telegram.

Выдача — `out/sealed_*.csv`; лог прогресса пишется в stderr.

## Лимиты

- **eBay Browse — 5 000 запросов в день**, сброс в 07:00 UTC = 10:00
  по Москве. Поиск по исполнителям — ~430 запросов, остальное — карточки.
- **Пачечная выдача карточек (getItems) нам закрыта — 403.** Карточки
  берутся по одной.
- **Кэш карточек** — `cache/ebay_cards.json`: штрихкод, номер и формат
  у лота не меняются, повторный прогон их не открывает заново. Цена
  всегда берётся из свежей выдачи. `cache/` в gitignore: кэш живёт, пока
  жив контейнер, в новом начинается с нуля.
- **Discogs — ~60 запросов в минуту на токен**, общий для всех прогонов:
  клиент читает остаток окна и уступает. Цены — только из
  `/marketplace/stats?curr_abbr=USD`: с токеном `/releases` отдаёт
  цену в евро аккаунта (O-79). Кэш — `cache/discogs_barcode.json`.
- Фоновая задача в окружении снимается через 2 часа.

## Уроки

- **Недооценены не пластинки, а стартовые цены отдельных продавцов.**
  wild.records в запечатанном, jazzlover1960 в джазе — аукционы с
  низкого старта. Там, где цену ставит рынок, почти всё стоит по Discogs.
- **Свежий тираж популярного исполнителя до $15 почти всегда стоит на
  Discogs около розницы.** Кратность — у распроданных лимиток (Green Day).
- **Пол Discogs — запрос в любом состоянии, не сделка.** Для запечатанной
  копии это осторожная опора: она стоит не дешевле. Продавать на Discogs
  придётся по полу или чуть ниже.
- **66% карточек без штрихкода** — в основном не пластинки; каталожный
  номер добавляет ~330 оценённых лотов за прогон, новых находок пока не дал.

## Что не сделано

- Полный прогон торга $15–20 по всем словам и исполнителям — не хватило
  дневного лимита eBay 23.10 (650 карточек из 2 677).
- Выдача продавцов-распродажников целиком (wild.records, jazzlover1960)
  — сигнал найден, отдельного режима нет.
