# Задание: снять цены МаркетВинила

Открой это в сессии на **claude.ai/code** (не в мобильной) и выполни.
Там у WebFetch полный доступ; в мобильной сессии он ограничен доменами
документации и до МаркетВинила не доходит — это и есть причина, по
которой задание отдельное.

Ветка — `claude/ebay-vinyl-3x-finder-q36cy3`, репозиторий уже склонирован.

---

## Зачем

Верхний сегмент eBay (лоты от $100) не с чем сравнивать: мешковская
медиана отключена как источник цены, потому что она даёт цену ОБЫЧНОЙ
копии, а верхний сегмент состоит из редких прессов. Разброс внутри
одного названия стократный — «Dark Side Of The Moon» в Москве уходил и
за 4 450 ₽ (переиздание), и за 450 000 ₽ (UK first press 1973).

Цены МаркетВинила — единственная оставшаяся линейка. Сейчас их в базе
165 по 53 позициям, но **с выдачей eBay они не пересекаются ни одной
позицией**: тот срез собирался по мешковскому спросу, а не по тому, что
реально продаётся на eBay.

Это задание закрывает разрыв.

---

## Что делать

**1. Возьми список.** `docs/mv_targets.json` — 250 позиций, из них
**95 с адресами карточек** (поле `candidates` непустое). Позиции уже
сверены: Discogs-резолв проверен сопоставителем `moscow_wantlist.title_matches`,
116 позиций отсеяно как «нашёлся другой альбом».

Каждая запись:

```json
{
  "sample_title": "Patrick Stump Soul Punk Smartpunk Records 12\" Vinyl Test Pressing LP",
  "max_price": 1300.0,
  "lots": 1,
  "release_id": 35956768,
  "master_id": 378792,
  "discogs": "Patrick Stump - Soul Punk",
  "candidates": [
    {"kind": "release", "url": "https://marketvinila.ru/release/35956768"},
    {"kind": "master",  "url": "https://marketvinila.ru/master/378792"}
  ]
}
```

**2. Открой карточки.** Сначала `release` (цена конкретного пресса),
и только если там пусто — `master` (цена альбома вообще). Вид карточки
обязан доехать до результата: это величины разного уровня.

Слаг в URL не нужен, `/{kind}/{id}` достаточно.

**3. Сними с каждой карточки, ДОСЛОВНО:**

* каждую цену в блоке предложений, с валютой;
* грейд винила и грейд конверта;
* `Edition` — страну и год издания. **Это ключевое поле**: на карточке
  мастера в одной колонке стоят разные прессы, и без издания цена
  бессмысленна (у The Idle Race — 4 390 ₽ за переиздание и 21 690 ₽ за
  оригинал 1968 года);
* носитель (`Media`) — карточка мешает винил, CD, кассеты и SACD;
* продавца и город;
* текст счётчика предложений («1–20 из 22»).

**4. Обойди пагинацию.** Карточка отдаёт 20 предложений на страницу,
`/{kind}/{id}/{page}/`, нумерация с нуля. Сортировка по возрастанию
цены — значит на первой странице дешёвый конец, а верхний сегмент живёт
в хвосте. При счётчике больше 20 обход страниц обязателен.

**5. Пустая карточка — это результат.** Записывай `"price_rub": null` и
`"note": "NO OFFERS BLOCK"`. Страница релиза может открываться и не
иметь ни одной копии в продаже, и такую позицию нельзя терять: она
отличается от «не смотрели».

**6. Лови soft-404.** Несуществующий id отдаёт **шаблон главной
страницы, а не 404**. Определяй по отсутствию заголовка релиза, иначе
запишешь мусор как карточку.

## Формат результата

Файл `data/mv_prices_<дата>.json`, массив объектов. **Одна строка —
одно предложение**, а не одна позиция.

```json
[
  {
    "release_id": 35956768,
    "master_id": 378792,
    "card_kind": "release",
    "url": "https://marketvinila.ru/release/35956768",
    "artist": "Patrick Stump",
    "album": "Soul Punk",
    "media": "Vinyl",
    "edition": "US 2011",
    "grade_media": "Near Mint (NM or M-)",
    "grade_sleeve": "Very Good Plus (VG+)",
    "price_verbatim": "5 200 ₽",
    "price_rub": 5200,
    "seller": "dj_bent",
    "city": "Отправка по РФ",
    "offers_counter": "1-1 из 1",
    "ebay_max_price_usd": 1300.0,
    "fetched_at": "2026-09-01T12:34:00Z"
  }
]
```

Обязательны: `release_id` или `master_id`, `card_kind`, `url`, `media`,
`price_rub`, `price_verbatim`, `fetched_at`. Остальное — по возможности.

`price_verbatim` нужен ОТДЕЛЬНО от `price_rub` намеренно: число разберут
дальше по конвейеру, а дословная строка позволяет поймать ошибку разбора.
Извлекатель, например, переформатирует «3 390 ₽» в «3,390 ₽».

---

## Протокол проверки, обязательный

Данные приходят через модель-извлекатель, а не парсером. Это источник
ошибок другого рода, чем сетевой отказ: **пропущенная строка выглядит
ровно как её отсутствие**, и поймать её потом нечем.

* **Только дословные цитаты.** Промпт извлечения обязан требовать
  verbatim. Любое число берётся со страницы, а не пересказывается.
* **Число строк обязано сходиться со счётчиком.** Расходится — карточка
  идёт на пересъём, а не в файл.
* **Сверка десяти.** Десять позиций открыть повторно и сверить
  поштучно. Расхождение хоть в одной — прогон бракуется целиком, а не
  правится в одной строке.
* **Кэш выборки 15 минут.** Повторную сверку делать не раньше чем через
  четверть часа, иначе сверяешь кэш сам с собой.
* **Дата и адрес у каждой цены.** Без них через месяц ряд неотличим от
  выдумки.

Почему настаиваю: в прошлый раз записка о сборе назвала индекс сайтмапов
«323 ссылки», а локальный пересчёт дал **386**; и «600+ URL в файле»
против фактических **5 000**. Оба числа пришли из пересказа выдачи.

## Правила обращения к сайту

Не решать и не эмулировать челлендж. Не брать куки и токены ниоткуда,
кроме обычной сессии. Не использовать сторонние прокси и антибот-сервисы.
Не ходить по адресам, запрещённым в robots. **Не трогать
`/product/<id>.json`** — HTML-карточка отдаёт те же поля, и щель не нужна.

**Не чаще одного запроса в секунду.** Доступ держится на доверии
владельца сайта, и на этом же домене копится наш еженедельный ряд
наблюдений за витриной. Домен дороже любого разового среза.

## Куда положить результат

**Закоммить файл в ветку `claude/ebay-vinyl-3x-finder-q36cy3` и запушь.**
Не присылай файлом — я подхвачу из репозитория сам.

```bash
git add data/mv_prices_*.json
git commit -m "Срез цен МаркетВинила по выдаче eBay: N предложений по M позициям"
git push -u origin claude/ebay-vinyl-3x-finder-q36cy3
```

В коммит впиши: сколько позиций обошёл, сколько с предложениями, сколько
пустых, сколько отбраковано по несходящемуся счётчику, и результат сверки
десяти.

## Что будет дальше

Загрузка идёт командой `python3 tools/mv_ingest.py data/mv_prices_<дата>.json`.
Загрузчик **не доверяет входу**: сверяет число строк со счётчиком и цену
с дословной записью, и по умолчанию НЕ грузит при замечаниях.

Дальше цена уходит в `upper_segment.ru_price_for()` с меткой `ask`
(выставленная цена, не сделка), проходит фильтр носителя — только винил —
и попадает в гейт: карго по замеренному весу 0.75 кг, пол прибыли
2 500 ₽, кратность 1.85x, реджект грейдов G/F/P.

И тогда сравнение eBay с МаркетВинила заработает на живой выборке —
впервые.
